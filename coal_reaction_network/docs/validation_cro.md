## 原有生产结果与限制

只读检查发现当前项目 v3 数据库实际已完成 20,002 帧 / 20,001 帧对，包含 5,575 条计量通道。
新增分类诊断接口在该数据库上只读查询耗时 7.488 秒，返回 61 类。
最大区间 `C40+_R10+_O3+` 的逐帧平均质量占比为 73.46%，平均碳占比为 81.86%；
另有 25,197 次类内连接变化，以及 2,150 次类别计量不变的多对多事件。
这些是区间分辨率与类内活动的诊断，不能据此直接认定区间应如何修改。
