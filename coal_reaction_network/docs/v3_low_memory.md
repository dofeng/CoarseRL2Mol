## 可恢复性边界

- 每帧/帧对的全部记录与 completed 状态在同一事务提交。
- 未消费或处理中的结果可安全重算，已完成事件不会重复插入。
- track 每帧 checkpoint；恢复载入上一帧映射，不需要全轨迹常驻内存。
- 时间标注、通道结果先写临时表，完成后事务发布；中断的临时阶段在恢复时重新计算。
- 输入或解析定义改变需要新数据库。时间过滤和守恒质量阈值可复用已解析数据。
- 运行中的原始文件应保持只读不变。默认 stat 指纹不是抗篡改证明，严格审计请加 SHA-256。

## 资源边界

- raw 全量数据仍保留，磁盘量会随帧数、片段数和事件数增长。
- 活动数据量由 worker 数、在途任务数、单帧/单帧对大小限制，而不是累计完成帧数。
- 内存中仍有小型文件清单与待处理任务元数据，故不能宣称对任意帧数严格 O(1)。
- RSS 是采样软保护，不是 cgroup/RLIMIT 硬限制；worker 极短时内存尖峰、其他独立进程不在此保证之内。
- 反转窗口存放在 SQLite 临时表；大量事件会增加磁盘工作量，而非构建整轨迹 Python 列表。
- 主数据库页缓存约 16MiB/连接，API 约 8MiB/连接；不要用增大缓存掩盖查询或调度问题。
- 有些帧有大量碎片，即使原子数不大，事件明细也可能较多。并发配置应按轨迹后期样本验证。

## 科学与界面边界

- 时间采样之间可能发生多个反应，只能识别观察到的净实例转化与 composite 事件。
- 拓扑指纹使用 atom ID 和阈值连接，不是同分异构分子 canonical identity；键级改变但连接不变不会单独识别。
- 独立环数不等于芳香环数；自由基属性仍是启发式估计。
- 逆转是候选，默认 off 不删反应；filtered 是可逆派生视图，不能替代 raw。
- 网络图按参与角色镜像物种，以清晰展示 A→A+B 等计量；同名两侧节点不是不同类别。
- 默认只显示一页通道，明确标注页面覆盖率。数据库并未因为分页而丢失低频通道。
- 导出的 SVG 是当前子图；需要完整统计使用数据库或流式网络导出。
- 当前不拟合反应速率/ODE，不根据频数自动宣称质量作用定律。

## 验收方法

1. 执行全部标准库回归测试，包含真实 bond0 样本、人工重排、原子交换、分裂融合、驻留/逆转和分页。
2. 比较 workers=1/2 的规范化事件结果；重复恢复结果不变。
3. 中断 track checkpoint 后恢复，与从头重建对比。
4. 运行 100、1000、10001 帧合成压力测试，确认总帧对 N−1、通道计数及 track 唯一性。
5. 用与真实输入相同的原子数量扩大单帧规模，观察各阶段进程树 RSS，而不是只看父进程。
6. 在新路径运行真实轨迹；检查 failed/blocked 为零，并确认文件编号规则、原子集合与类别定义。
7. 在浏览器检查布局、缩放、SVG 导出和不同屏幕尺寸。自动 HTTP/JavaScript 检查不等同视觉像素验收。

旧数据库未迁移或覆盖。完整真实长轨迹应由使用者确认输入路径和资源条件后，在新路径重跑。
