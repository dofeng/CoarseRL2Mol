# 界面与统计口径审查

## 真实结果的口径核对

对已有 `results/reaction_network_v3/network.sqlite` 进行只读核查：

| 统计项 | 数量 |
| --- | ---: |
| 完成帧 / 相邻帧对 | 20,002 / 20,001 |
| 出现的 C/R/O 类别 / 完整计量通道 | 61 / 5,575 |
| 非持续反应事件 | 88,189 |
| 类别数量变化事件 | 60,842 |
| 类别数量不变的活动 | 27,347 |
| 持续存在事件，不计为反应 | 11,026,756 |
| 跨类别累计碳转移 | 538,927 |
| 类别内累计碳转移 | 42,985,556 |

类内转移约占累计碳转移的 98.8%。这些数字累计的是参与事件且留在同类别的原子，不能解释为净产物生成、发生改变的键数或反应速率。因此界面默认按类别数量变化和事件次数展示主要完整计量通道；物质流排序默认关闭类内对角项，同时公开跨类与类内分项。原始事件均保留，可切换观察全部活动。

类别数量不变不等于分子没有反应。例如连接重排与 `2A -> 2A` 原子交换仍是观察到的活动。统计对象由完整两侧计量是否相等决定，不由某一个事件类型代替。

## 逻辑修正

- 通道、物质流与事件证据共用时间窗、视图、统计对象、物种、C/R/O 区间、事件类型和解析等级条件。组合区间必须由同一个参与类别同时满足。
- 展示完整两侧计量，另外计算每次事件的净类别系数；`A -> A + 2B` 保留 A 的双侧参与，净变化单列为 B 的 +2。
- 聚合保留事件类型分项；存在多类型时标记 mixed。完整缓存通道也返回实际起止帧。
- 概览将反应事件与持续存在分别计数；区间事件统计明确为该帧范围内的原始全部类别，网络覆盖率则基于当前事件筛选。
- 转移权重公开跨类与类内碳/氧/质量及零权重事件数。零碳或零氧权重不表示没有反应。
- 重算检查点已覆盖的旧帧或帧对时，使实例轨迹、驻留统计、时间标注失效；后续恢复重新构建，避免发布过期的寿命结果。
- Notebook 的监听地址与 Dashboard 本机限制一致。

类别占用率原实现已正确按指定时间窗选取帧；新增回归覆盖该行为，没有修改其平均定义。观察频次、类别净变化和累计物质流仍不能直接替代机理识别或动力学参数。

## 界面调整

工作区采用筛选、镜像计量图、证据面板三栏；计算任务移入对话框。稳定 P 编号与明确 C/R/O 边界共同标识类别，保留数据库原始 ID。通道表、区间事件分项、组成曲线和守恒表使用统一布局。手机筛选默认折叠，固定格式网络支持滚动和缩放。图标在本地提供，无前端 CDN 依赖。
