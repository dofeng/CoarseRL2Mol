# 时间路径与可旋转三维视图

## 使用

从仓库根目录启动或重启服务：

```bash
python3 coal_reaction_network/src/network_dashboard.py --port 8765
```

1. 加载已完成帧和相邻帧事件的 v3 数据库。本功能不依赖新增物质流表，无需重新解析 bond 文件或对生产数据库做迁移。
2. 选择起止帧。这里使用数据库帧序号，不是文件名中的数字或物理时间。
3. 选择前向 / 反向；前向锚点是起始帧，反向锚点是结束帧。
4. 在“聚焦物种”选择锚点类别，或者填写锚点帧的片段 ID；片段 ID 优先。
5. 可选另一端类别约束。它取两端实际原子集合的交集；没有共同原子时明确报错，不用类别最短路伪造路径。
6. 点击“构建路径”，等待后台扫描。默认显示全区间二维阶段流程，默认 4 阶段，可选 8/12/16 阶段；阶段事件计数覆盖整个区间，不受单页 30 事件限制。
7. 在二维阶段流程、三维阶段流程、压缩事件三维图和原始逐事件二维图间切换无需重算。点击过程查看实际边界原子去向，再展开逐事件证据。展开保持原查询锚点，从该阶段首个相关事件开始重新扫描取页；此页可能延伸到后续阶段。
8. 逐事件模式默认每页 30 个相关事件，点击“后续事件”继续查看。阶段总览不分页；它不是只比较初始、最终两帧。

“跳过前 N 个相关事件”可直接定位事件页，避免对长轨迹逐页点击；排序始终为帧对及事件号。

若选定区间只有持续存在，将显示驻留状态而非虚构反应。缺帧或未完成帧对阻止连续路径生成。
“应用筛选”不是构建路径：修改路径条件后须重新点击“构建路径”。旧结果的摘要仍显示原结果范围 / 锚点。
通道次数、物质流权重、时间去噪等原有筛选不应用于路径，防止它们悄悄删掉中间过程。

## 交互

- 二维：固定高窗口、纵横滚动条，滚轮上下滚动，Shift＋滚轮左右滚动，不改变 viewBox 或比例。
- 三维：左键拖动空白处旋转；Shift＋拖动平移；仅在按住左键时滚轮缩放，并以光标位置为中心。释放左键后普通滚轮不再改变相机。
- 比例滑块与加减按钮支持 5%–400%；“适应”根据当前网络边界适配全图，必要时可小于 5%，实际比例显示在滑块上方。三维底部时间浏览条可左右查看，不创建巨幅渲染窗口。
- 默认“时间阅读”限制旋转范围；“自由观察”允许更大角度，但不能保证屏幕上仍左早右晚。“适应”恢复正向时间视角。“三维纵深展开”调整分支深度，不改变反应关系；“聚焦选中节点”定位当前选中对象。
- 现有计量图和物质流图也取消滚轮缩放，完整画布在容器内滚动。
- 选中对象不再将其他计量边降到几乎不可见。
- SVG 导出保存当前静态投影；路径 JSON 保存查询条件、当前事件页、压缩页、全区间阶段摘要及原始证据定位信息，不是全部逐事件路径文件。

三维实现为原生 SVG 的三维坐标正交投影，执行 yaw/pitch 旋转与深度排序，不依赖 WebGL、外部 CDN 或运行时第三方 JS 包。
所有路径视图统一按 X 轴时间从左到右展开，不再蛇形折行或沿 Y 轴排列事件。默认紧凑刻度对出现的时间位置等间距排列，压缩空白时间，明确标注为非等比例；可切换“真实帧距”使用线性帧坐标。事件放在其帧区间中点；持续状态从 first_frame 到 last_frame 绘制驻留线段，后续反应从驻留末端连接。

Y 通道按时间顺序分配并预约驻留区间，主要产物优先继承父通道，分支使用邻近空闲通道；汇合优先靠近主要输入。阶段类别群组优先保持同类通道，仅为布局便利，不据此推断原子路径。Z 深度继承主要父支路，新增侧支进入下一纵深层，共同参与者位于后方；不是 Y 坐标的线性映射或节点序号取余。密集阶段摘要适度增加横向间距。曲线控制点沿时间方向布线，未旋转时不折返；同通道边保留小幅弯曲。

深度只用于展开分支，不代表能垒、化学距离或额外分类维度。这是确定性的通道分配，不是全局最少交叉求解器，不能保证任意旋转视角下无交叉或遮挡。三维仍采用 SVG 正交投影，未迁移到 WebGL / Three.js。

旋转、平移与缩放通过 requestAnimationFrame 更新已有图形坐标，不再重建 SVG、表格、图例或点击事件。拖动时暂时隐藏标签，松开后重新避让；低于 30% 时默认只保留选中节点标签，悬停与详情仍可查看证据。三维节点随缩放适度变小以减少总览拥挤。窗口大小变化时更新视窗，布局不重新随机计算。
这是有明确显示上限的路径阅读器，不是面向无限节点的通用三维图引擎。

## 追踪语义

固定锚点原子集合，顺序扫描区间内每一个相邻帧对。每帧解压当前片段的原子 ID，通过集合交集确定追踪原子在哪些片段中。
同类别但不含追踪原子的独立片段不会被串入路径；它们参与选中事件时仅作为上下文出现，不扩张锚点集合。
同一个中间实例既是前一事件产物，又是下一事件反应物时，共享同一状态节点；不是两列互不相连的类别名称。
分裂、融合、多对多及类内变化保留原始完整参与者与系数；连续 persistence/coarse_persistence 压缩为时间区段。
压缩仅表示已有事件识别器判定的持续状态，不证明不存在阈值图之外的键级变化。
同类不同时间 / 不同实例具有不同状态 ID，但仍使用同一个 C/R/O 类别定义。

### 阶段摘要与压缩页

阶段摘要使用均匀帧区间，不是自动筛选关键化学转折。边界节点是同一 C/R/O 类别的追踪原子群组，过程块汇总阶段内的相关事件类型与次数。它不表示单步反应，也不能把一个过程块的任意输入和输出组合成真实路径；详情中的 `transfers` 给出实际边界原子对应。短寿命中间体可能不在边界出现，必须展开逐事件证据查看。没有事件的阶段记录零次事件，不虚构反应。

压缩事件三维页只合并单输入、单输出、类别和追踪原子数均不变的 `internal_rearrangement`，保留每次原始事件入口。分裂、融合或交换不会仅因类别相同就被折叠。原始二维事件页不受此压缩影响。

逐事件图的橙色边表示**单次事件中追踪原子数最多的输入 / 输出分支**；并列最大者均标记。阶段摘要的橙色仅表示阶段边界的最大原子群组，不代表已经求得一条全局核心路径。
蓝色表示其他追踪分支，灰色表示未携带追踪原子的共同参与者。
它是局部主要谱系的可视提示，不是全局最优、唯一核心机理，也不是按碳流或质量选择的路径。
本版权重使用全元素原子数；选择碳、氧或质量加权需要额外的原子元素信息及独立实现，不能把当前计数称为碳贡献。
元素发生真实进出时报告原子缺席帧次数；累计缺席不是独立丢失原子数。原子 ID 的稳定性是追踪前提。

## 名称与颜色

内部 species_id 保持不变，不迁移旧事件签名。展示增加固定分类配置下的 P 编号，按 C/R/O 区间笛卡尔顺序生成；不同分类配置之间不能仅凭 P 编号比较。
例如 `C40+` 明确显示为 `C≥41`，R 同理，避免误解边界。没有根据 C/R/O 自动附加芳香性、焦炭等无法证实的物种名称。
路径状态显示 P 编号、区间和时间；事件使用 `E事件号@帧号`，不再与 R 环数混淆。
节点颜色固定映射 C 区间，详情保留完整区间。复杂三维页减少默认标签，悬停和选中仍能查看，不删除状态证据。

## 模块

| 模块 | 职责 |
|---|---|
| `src/pathway/tracing.py` | 只读原子追踪、状态衔接、持续段压缩、事件分页 |
| `src/pathway/tasks.py` | 单任务后台执行、取消、进度及派生 JSON |
| `src/pathway/summary.py` | 全区间有限边界快照、阶段计数及真实原子对应 |
| `src/pathway/compression.py` | 事件页内安全类内变化压缩及证据保留 |
| `src/web/graph-ui.js` | 类别展示名称、固定画布尺寸、显式缩放 |
| `src/web/graph-ui.css` | 固定视窗、滚动条、路径面板与标签 |
| `src/web/pathway-view.js` | 视图切换、渲染、阶段展开、证据和导出 |
| `src/web/pathway-layout.js` | 时间坐标、稳定通道、驻留区间、空间投影与曲线 |
| `src/web/pathway-camera.js` | 旋转、平移、左键＋滚轮定点缩放 |
| `src/web/pathway-scene.js` | 保留式 SVG 场景、增量投影、标签避让、全图适配与聚焦 |

接口：POST `/api/pathway/start`、POST `/api/pathway/cancel`、GET `/api/pathway/status`、GET `/api/pathway/result`。
路径结果写入 `results/pathway_tasks/`，生产数据库以只读 SQLite 快照打开。任务结束即释放快照，长时间查询期间同时写入源数据库可能增加其 WAL 占用，建议不要同时重算同一数据库。

## 内存和边界

- 只保留锚点集合、相邻两帧片段、当前页图和最多 17 个边界快照，不建立全轨迹 Python 图。摘要最多 1600 个边界类别状态；资源消耗仍随锚点原子数增长。
- 单页最多 300 个相关事件、4000 个状态。超出状态上限明确报错，需减少单页事件或选择更具体的片段，不静默丢弃共同参与者。
- 扫描整个区间以返回相关事件总数；分页仍重新扫描原区间。默认 30 个事件便于阅读，但不是“核心事件自动总结”。
- 跨页没有伪造的直接连接；每页保留其实际时间信息。已实现全区间均匀阶段摘要，尚未实现任意层级分支折叠、自动关键阶段识别或全部路径枚举。
- 后台支持取消，取消后重新查询；尚未实现帧级持久断点恢复。服务重启后需重新发起查询，已生成 JSON 文件仍留在派生结果目录。
- 未增加噪声识别算法，路径继承已有阈值化事件的观测局限。

## 验证

`python3 -B coal_reaction_network/tests/run_tests.py` 包含路径链、无关同类隔离、共同参与者、反向锚点、持续段压缩、分页、缺帧拒绝、取消及后台 HTTP 测试。
本次完整回归结果为 83 项通过；新增阶段全区间计数、边界原子对应、零事件和安全压缩回归；另通过 JS 布局、模拟 DOM 冒烟及真实浏览器交互验收。

可选真实浏览器验收脚本：`tests/browser_pathway_check.py`。需要单独准备 Playwright / Chromium，不是项目运行依赖。
脚本验证曲线连接、阶段说明、旋转改变投影且保留 SVG 与表格 DOM、左键＋滚轮缩放及释放后不缩放、5% 缩小、二维横向和纵向滚动、旧通道图滚轮不缩放，并输出阶段流程和二维 / 三维截图。可传 `--result 路径.json` 只读加载已有路径结果，额外验证真实数据的三种视图，不重算生产数据库。

`node coal_reaction_network/tests/test_pathway_layout.js` 验证时间单调性、分裂 / 汇合通道继承、驻留区间、曲线不折返、真实帧距和输入证据不变；`node coal_reaction_network/tests/test_web_smoke.js` 验证前端模块集成。

对已有生产 v3 数据库执行了一次只读验证：帧 0–20001，起始片段 1，发现 48,289 个相关事件，4 阶段摘要计数同为 48,289，保留 54 个边界类别状态；原始页取前 30 个事件，压缩页合并其中 22 个类内变化。耗时约 75.36 秒，查询进程峰值 RSS 约 34.10 MiB。
这是一个特定锚点查询，不是所有类别 / 所有查询的资源上限，也不包括浏览器内存；未改写生产数据库。

使用临时安装的 Playwright 与无头 Chromium 运行浏览器验收，而非仅模拟 DOM。图形区域保持固定高度，内容通过滚动浏览；性能结果取决于当前页节点数和设备，未承诺固定帧率或全量 20,000 帧同时渲染。
